# Snapshots documentais

Rodadas fechadas dos documentos finais, agrupadas por data. Cada pasta datada é imutável: uma atualização cria nova rodada, nunca substitui retroativamente conteúdo de uma rodada anterior.

O [`documentation/README.md`](../README.md) define os seis artefatos esperados por rodada (três Markdown e três Word). ORG-PREP adiciona somente este guia ao contêiner; não toca nas pastas datadas.

## Inventário dos arquivos migrados

Nenhuma rodada foi movida. Quando houver nova rodada: pasta | data | fontes usadas | validação dos formatos.
