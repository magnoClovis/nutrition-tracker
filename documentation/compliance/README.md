# Compliance canônico proposto

Destino proposto para políticas e declarações regulatórias cuja fonte canônica venha a sair da raiz em ORG-1. Ainda não existe conteúdo operacional migrado aqui. As cópias atuais em [`estado-atual/compliance/`](../estado-atual/compliance/README.md) devem permanecer intactas até a origem e a publicação de cada política serem reconciliadas.

Mover uma política exige preservar PT/EN/ES quando aplicável, URLs públicas, referências no app/Play e cópias controladas. Não presumir que criar este diretório mude uma política publicada.

## Inventário dos arquivos migrados

Nenhum documento foi migrado. Ao migrar: arquivo | política/idioma | origem canônica | URL/consumidores | cópias/gate.
