# Guias operacionais

Procedimentos para automações, entrega de AAB, validação física, monitoramento e outras operações recorrentes. Diferem dos retratos em `estado-atual/`: devem permitir execução segura com pré-condições, verificação e rollback quando aplicável.

Não incluir segredos, tokens, dados de contas reais ou passos destrutivos sem escopo/confirmação. Mudanças que afetem um guia operacional precisam atualizá-lo no mesmo PR da mudança de produto ou infraestrutura.

## Inventário dos arquivos migrados

Arquivos existentes serão classificados na ORG-0. Ao mover: arquivo | operação | origem | responsável | pré-condições/gate.
