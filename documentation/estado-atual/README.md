# Estado atual do Trofia

Retrato versionado de capacidades, riscos, planejamento e contratos vigentes. [`RESUMO-STATUS.md`](RESUMO-STATUS.md) é o índice breve; documentos específicos aprofundam políticas, arquitetura, rollout e operação.

Alguns arquivos são cópias controladas de originais da raiz; seu cabeçalho identifica a fonte. Atualizar original e cópia no mesmo PR quando o conteúdo operacional mudar. Não transformar um snapshot histórico em fonte atual.

## Inventário dos arquivos migrados

Arquivos pré-existentes serão classificados na ORG-0. Ao mover: arquivo | propósito | origem canônica/cópia | leitores | regra de sincronização.
