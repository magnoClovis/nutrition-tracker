# Cópias de compliance no estado atual

Este diretório já contém cópias controladas de políticas de privacidade e declaração Google Play. Ele não substitui automaticamente a fonte operacional original. O futuro [`documentation/compliance/`](../../compliance/README.md) é um destino canônico proposto, cuja adoção depende da matriz ORG-0 e da atualização de links/publicação.

Ao alterar uma política, verificar a fonte, idiomas, publicação e cópia no mesmo PR. Não colocar dados pessoais, credenciais ou artefatos de usuários nos documentos.

## Inventário dos arquivos migrados

Arquivos existentes serão mapeados pela ORG-0. Ao mover: arquivo | público/idioma | fonte | publicação/leitores | sincronização.
