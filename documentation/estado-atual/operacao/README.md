# Cópias operacionais do estado atual

Este diretório contém cópias versionadas de guias e referências operacionais. Não é sinônimo de [`documentation/operacao/`](../../operacao/README.md), que guarda guias de execução próprios; a origem de cada arquivo deve ser identificada antes de qualquer consolidação.

Manter comandos, pré-condições, credenciais omitidas e referências do projeto sincronizados. A ORG-0 decidirá por evidência quais cópias permanecem necessárias.

## Inventário dos arquivos migrados

Arquivos existentes serão classificados na ORG-0. Ao mover: arquivo | objetivo | origem/cópia | usuário do guia | regra de atualização.
