# Projeto Android

Projeto Capacitor/Gradle do pacote `com.hermegas.trofia`. Aqui ficam a configuração nativa e os recursos Android; não é destino genérico para lógica web ou documentação de produto.

Build release exige `google-services.json` real, versão correta e assinatura verificada. Keystore, senhas e arquivos locais sensíveis não são exemplos a copiar para o Git. Mudanças de caminho feitas pela ORG exigem provar que `webDir: dist`, empacotamento e validação Play permanecem íntegros.

## Inventário dos arquivos migrados

Arquivos existentes serão auditados na ORG-0. Ao mover: arquivo | finalidade | origem | consumidor Gradle/Capacitor | prova de build.
