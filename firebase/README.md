# Configuração Firebase

Destino planejado para rules e índices declarativos do Firestore. Os arquivos ativos `firestore.rules` e `firestore.indexes.json` ainda permanecem na raiz, conforme `firebase.json`; criar este diretório não muda regras publicadas.

ORG-3 deverá atualizar caminhos, emuladores, scripts e CI no mesmo PR, com dry-run e validação de escrita/leitura antes de qualquer deploy autorizado. Nunca armazenar aqui credenciais, exportações de usuários ou arquivos locais de configuração sensível.

## Inventário dos arquivos migrados

Nenhum arquivo de produto foi migrado. Ao migrar, registrar: arquivo | função | origem | consumidor em `firebase.json` | prova de validação.
