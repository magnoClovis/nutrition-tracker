# Componentes de apresentação

Componentes de interface reutilizáveis e seus adaptadores de apresentação vivem aqui. Alguns arquivos já existem nesta pasta; ORG-PREP não os move nem altera. Regra de negócio, persistência e configuração de plataforma devem permanecer em fronteiras próprias quando a matriz ORG-0 confirmar a separação.

Mudanças precisam preservar acessibilidade, PT/EN/ES, desktop/mobile, temas, fonte ampliada e a compatibilidade do legado e do Vite. Não apagar um adaptador apenas porque parece duplicado.

## Inventário dos arquivos migrados

Arquivos pré-existentes serão catalogados na ORG-0. Para cada migração posterior, adicionar: arquivo | função | origem | consumidores | contrato visual/funcional.
