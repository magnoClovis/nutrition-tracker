# Agrupamento composto atual

Este diretório já reúne adaptadores/componentes compostos do cliente. Seu nome e fronteira são transitórios: ORG-5 decidirá, com o grafo de imports, o que pertence a `features/`, `components/` ou outra camada.

Não remover nem deslocar arquivos apenas por semelhança de nome. Preservar os consumidores UMD/ESM e os testes de cutover durante a migração.

## Inventário dos arquivos migrados

Os arquivos pré-existentes serão catalogados pela ORG-0. Para novos movimentos: arquivo | função | origem | consumidores | prova de compatibilidade.
