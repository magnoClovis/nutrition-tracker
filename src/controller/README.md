# Adaptadores de controlador atuais

Este diretório existente participa da composição Vite do controlador. O controlador legado ainda está na raiz; ORG-6 só poderá extraí-lo depois de caracterizar hooks, efeitos, hidratação e autosave.

Não presumir que um adaptador pequeno substitui o módulo original. Verificar chamadas, globais e importações dos dois runtimes antes de alterar caminhos.

## Inventário dos arquivos migrados

Arquivos pré-existentes serão mapeados na ORG-0. Para cada migração: arquivo | papel | origem | consumidores | testes.
