# Integrações de plataforma

Destino para adaptadores do cliente que dependem de capacidades web, Android ou Capacitor: câmera, ciclo de vida, permissões e APIs do dispositivo quando sua posse for confirmada. Código nativo Gradle continua em `android/`.

Separar interface comum de implementação por plataforma sem simular Play Integrity, câmera ou permissões reais em validações que exigem Play/Galaxy.

## Inventário dos arquivos migrados

Nenhum arquivo de produto foi migrado. Ao migrar, registrar: arquivo | capacidade | origem | consumidores | prova web/Android.
