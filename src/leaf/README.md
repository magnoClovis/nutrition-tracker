# Módulos folha atuais

Este diretório existente foi usado no cutover para organizar módulos de menor acoplamento. ORG-5 revisará a posse de cada arquivo entre `domain/`, `features/`, `services/`, `platform/` e `compat/`; não haverá exclusão baseada só no nome `leaf`.

Manter importações Vite, contratos UMD e testes de equivalência até a migração comprovada.

## Inventário dos arquivos migrados

Arquivos pré-existentes serão catalogados pela ORG-0. Para novos movimentos: arquivo | função | origem | consumidores | validação.
