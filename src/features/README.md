# Funcionalidades do cliente

Destino para módulos coesos por jornada, como Diário, refeições, foto, perfil e métricas, quando a matriz ORG-0 comprovar seus limites. Componentes genéricos vão para `components/`; cálculo puro, para `domain/`; comunicação externa, para `services/`.

Não criar subpastas por nome de tela nem mover controladores grandes sem testes de caracterização e consumidores mapeados.

## Inventário dos arquivos migrados

Nenhum arquivo de produto foi migrado. Ao migrar, registrar: arquivo | jornada/função | origem | consumidores | regressões cobertas.
